Project Experience

  1. (BDSC 2025) Intelligent Social Governance Challenge — First Place
    • In the BDSC Conference - Intelligent Social Governance Challenge hosted by the Chinese Association for Artificial Intelligence, participants were required to design a regulatory agent. With a limited intervention quota, we aimed to minimize the spread of rumors in social networks through reasonable detection and intervention strategies. Our team designed fine - grained intervention strategies based on social network analysis and eventually outperformed teams like ASCII Lab of the Chinese Academy of Sciences to win first place.
  2. Decoupling GCN for Point - Cloud Classification
    • I used GCN to perform single - view sampled point - cloud classification on the ModelNet40 dataset. I decoupled the GCN framework into Propagation and Transform. Inspired by centrality calculation in social networks, I used node centrality - weighted graph convolution to better capture the local structure of point clouds. Ablation experiments showed a significant improvement in Overall Accuracy compared to the baseline (Resconnection GCN).
  3. FT/RLHF LLM for Math - Solving
    • Using Qwen3 - 0.6B as the baseline model, I explored different technical approaches to enhance its ability to solve primary school math problems: LoRA fine - tuning on the dataset; CoT and data augmentation: optimizing prompts to make the LLM solve problems according to the chain of thought. I used stronger LLMs to generate standard problem - solving steps to augment the training set and performed SFT using data with correct answer steps; DPO: constructing correct/incorrect CoT datasets to minimize the log - probability difference of [preferred - non - preferred] response training pairs between the model and the potential optimal strategy.
  4. MapReduce - based Large - Scale Text Clustering
    • I deployed a five - node cluster and used the MapReduce framework and parallel Louvain algorithm to cluster 800,000 groups of long Q&A texts from Stack Overflow. To efficiently handle large - scale sparse networks, I built a similarity matrix based on discrete features and designed a MapReduce parallel algorithm starting from heterogeneous graphs, which significantly improved computational efficiency. When using five machines in parallel, it only took 40 minutes to build the similarity matrix (O(800,000^2)) on the dataset of 800,000 groups of long texts. Based on the idea of community discovery, I used the parallel Louvain algorithm for clustering on the similarity matrix.
  5. MIT 6.037: Structure and Interpretation of Computer Programs
    • I learned about type systems and the principles of functional languages. I completed all the experiments of the MIT 6.037 course and independently wrote an interpreter for the target language of LSTC using the Racket language. It implemented Scope Hierarchy, curried function parameters, built - in function signatures, and supported syntax sugars like let and let*, type checking, and syntax error reporting.
